# Real-Finan 运行指南

## 环境配置

### 基础要求

| 项目 | 最低要求 | 推荐 |
|------|----------|------|
| 操作系统 | Windows/Linux/macOS | Linux (生产) |
| Python | 3.10+ | 3.12 |
| 内存 | 2GB | 4GB+ |
| 磁盘 | 500MB | 2GB+ (含 outputs/uploads) |
| 网络 | 出站HTTPS访问 | 稳定连接 (API调用) |
| Redis | 可选 | 6.0+ (异步任务) |
| Neo4j | 可选 | 5.x (知识图谱) |

### 依赖安装

```bash
# 创建虚拟环境
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# 或 .venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

| 包 | 用途 |
|----|------|
| langgraph | Agent 编排框架 |
| fastapi + uvicorn | REST API |
| httpx | HTTP 客户端 (LLM API + 行情 API) |
| sqlalchemy | ORM 数据库 |
| redis + rq | 异步任务队列 |
| neo4j | 图数据库 (可选) |
| pymupdf | PDF 文本提取 |
| python-multipart | 文件上传解析 |
| yfinance | Yahoo 行情数据 |

### 环境变量

```bash
# === LLM 配置 (核心) ===
export DEEPSEEK_API_KEY="sk-xxxxxxxx"       # DeepSeek API 密钥
export DEEPSEEK_MODEL="deepseek-chat"        # 模型名 (默认)
export DEEPSEEK_BASE_URL="https://api.deepseek.com"  # API 地址
export DEEPSEEK_TIMEOUT_SECONDS="45"          # 超时时间

# === 服务配置 ===
export MAS_HOST="127.0.0.1"                 # API 监听地址
export MAS_PORT="8000"                       # API 端口
export MAS_API_KEY="your-secret-key"         # API 鉴权 (不设则跳过)

# === 存储配置 ===
export MAS_OUTPUT_DIR="outputs"              # 报告输出目录
export MAS_UPLOAD_DIR="uploads"              # PDF 上传目录
export MAS_DATABASE_URL="sqlite:///data/real_finan.db"  # 数据库
export MAS_DB_PATH="data/real_finan.db"      # SQLite 文件路径

# === 异步任务 (可选) ===
export MAS_REDIS_URL="redis://localhost:6379/0"  # Redis 连接
export MAS_REDIS_QUEUE_NAME="finance-analysis"    # 队列名

# === 知识图谱 (可选) ===
export MAS_NEO4J_URI="bolt://localhost:7687"
export MAS_NEO4J_USERNAME="neo4j"
export MAS_NEO4J_PASSWORD="password"

# === 行情数据 ===
export MAS_MARKET_DATA_PROVIDER="yahoo"      # yahoo | alphavantage
export ALPHAVANTAGE_API_KEY="xxx"            # Alpha Vantage 密钥
```

## 快速开始 (三种模式)

### 模式 1: CLI 演示 (最简单,无需 API Key)

```bash
# 不需要任何外部服务,不需要 API Key
python run_demo.py

# 自定义分析 query
python run_demo.py --query "分析 Apple 2025 年的研发投入与供应链风险"

# 输出完整 JSON state
python run_demo.py --json

# 指定报告输出目录
python run_demo.py --output-dir ./my_reports
```

输出文件在 `outputs/` 目录:
- `{thread_id}_{timestamp}_report.md` — 11 章机构级分析报告
- `{thread_id}_{timestamp}_audit.json` — Agent 审计日志
- `{thread_id}_{timestamp}_state.json` — 完整状态快照

### 模式 2: API 服务 (DeepSeek API Key 推荐)

```bash
# 设置 API Key (可选,不设则用 local-fallback)
export DEEPSEEK_API_KEY="sk-xxxxxxxx"

# 启动 API 服务
python start_api.py

# 另开终端测试
curl -X POST http://127.0.0.1:8000/api/v1/analyze \
  -H "Content-Type: application/json" \
  -d '{"query": "对比分析 Apple 与 Microsoft 的供应链风险和研发投入。"}'

# 上传 PDF 分析
curl -X POST http://127.0.0.1:8000/api/v1/analyze-upload \
  -F "query=分析这份 Tesla 财报的风险" \
  -F "files=@/path/to/Tesla_10K.pdf"

# 健康检查
curl http://127.0.0.1:8000/health

# 查看 API 文档 (Swagger UI)
open http://127.0.0.1:8000/docs
```

### 模式 3: 异步任务队列

```bash
# 需要 Redis 运行中
docker run -d -p 6379:6379 redis:7-alpine

# 终端 1: 启动 API
export MAS_REDIS_URL="redis://localhost:6379/0"
python start_api.py

# 终端 2: 启动 Worker
python start_worker.py

# 提交异步任务
curl -X POST http://127.0.0.1:8000/api/v1/jobs \
  -H "Content-Type: application/json" \
  -d '{"query": "分析 Apple 2025 财报的供应链附录风险。"}'

# 查询任务状态 (用返回的 job_id 替换)
curl http://127.0.0.1:8000/api/v1/jobs/{job_id}

# 列出最近的任务
curl http://127.0.0.1:8000/api/v1/jobs?limit=10
```

## Docker 部署

```bash
# 构建镜像
docker build -t real-finan .

# 运行 (无 Redis)
docker run -p 8000:8000 \
  -e DEEPSEEK_API_KEY="sk-xxxxxxxx" \
  -v $(pwd)/outputs:/app/outputs \
  -v $(pwd)/data:/app/data \
  real-finan

# 运行 (带 Redis)
docker run -p 8000:8000 \
  -e DEEPSEEK_API_KEY="sk-xxxxxxxx" \
  -e MAS_REDIS_URL="redis://host.docker.internal:6379/0" \
  -v $(pwd)/outputs:/app/outputs \
  -v $(pwd)/data:/app/data \
  real-finan

# 启动 Worker 容器 (需要同一个 Redis)
docker run --rm \
  -e DEEPSEEK_API_KEY="sk-xxxxxxxx" \
  -e MAS_REDIS_URL="redis://host.docker.internal:6379/0" \
  -v $(pwd)/outputs:/app/outputs \
  -v $(pwd)/data:/app/data \
  real-finan python start_worker.py
```

## 监控与调试

### 日志

系统通过 Python logging 输出到 stdout:
```
2026-05-14 10:30:15 INFO real_finan.api request_id=a1b2c3d4 method=POST path=/api/v1/analyze status=200 duration_ms=18234
```

每个 HTTP 请求自动分配 `request_id` (8 位 hex),响应头中返回 `X-Request-Id`。

### 审计日志

每次分析生成的 `_audit.json` 记录了每个 Agent 的执行状态:
```json
[
  {"step": "supervisor", "status": "ok", "detail": "Strategic orchestration initiated for 2 companies. ..."},
  {"step": "retrieval", "status": "ok", "detail": "Data fusion complete: ..."},
  {"step": "quant", "status": "ok", "detail": "Quantitative engine computed 10 metrics across 2 companies. ..."},
  ...
]
```

### 完整 State 快照

`_state.json` 包含分析的完整中间状态——如果报告中的某个数字看起来不对,可以回溯到对应 Agent 的 state 快照,检查输入数据是否正确。

### 常见警告和含义

| 现象 | 原因 | 处理 |
|------|------|------|
| `llm_backend: "local-fallback"` | DeepSeek API Key 未设置或调用失败 | 检查 `DEEPSEEK_API_KEY` 环境变量是否设置且有效 |
| `market_snapshots` 中所有字段为 null | yfinance API 波动或无网络 | 正常——系统会用样本数据和 PDF 数据兜底 |
| `[Degraded Analysis]` 标记 | 经过 2 次重试仍数据不足 | 检查 query 中的公司名是否在 `SAMPLE_FINANCIAL_DATA` 或 `DEFAULT_TICKER_MAP` 中 |
| `replan_reason: "Appendix data gap detected"` | 某公司的数据缺少附录信息 | 正常第一次重试路径,第二次将激活降级模式 |
| `compliance_findings` 非空 | 报告缺少风险免责声明或数据来源标注 | 如果用的是 local-fallback,compliance 模板可能未覆盖所有场景 |

## 数据准备

### 使用内置样本数据

系统内置了 Apple 和 Microsoft 的 2025 年样本数据 (`data/sample_financial_data.py`)。无需额外配置,直接在 query 中提到这两家公司即可使用。

### 上传 PDF 财报

支持的 PDF 格式: 任何 PyMuPDF 可读的 PDF 文件（包括中英文）。

系统会自动:
1. 提取全文文本
2. 识别公司名 (14 个预设中英文别名)
3. 提取 Revenue/EBITDA/R&D 指标数值（带单位自动换算）
4. 检测供应链讨论信号

API 方式:
```bash
curl -X POST http://127.0.0.1:8000/api/v1/analyze-upload \
  -F "query=分析这份年报的核心财务指标和风险" \
  -F "files=@/path/to/annual_report.pdf"
```

CLI 方式:
`run_demo.py` 当前不支持上传文件，需要用 API 的 upload 端点。

### 实时行情数据

Yahoo Finance 提供免费、无需注册的行情数据接入。覆盖全球主要交易所（美股、港股、A 股部分）。系统在 `DEFAULT_TICKER_MAP` 中预置了 14 家公司的股票代码映射。

如需更稳定的数据,可注册 Alpha Vantage 免费 API Key (每天 25 次请求):
```bash
export MAS_MARKET_DATA_PROVIDER="alphavantage"
export ALPHAVANTAGE_API_KEY="your-key"
```

## 常见问题

**Q: `pip install` 报 neo4j 找不到？**
A: neo4j 包在某些环境下可能安装失败。临时解决——从 `requirements.txt` 中删除 neo4j 行再安装。系统会自动降级为 NetworkX 内存图,不影响核心功能。

**Q: 运行 `python run_demo.py` 输出乱码？**
A: Windows 下需要设置终端编码: `chcp 65001` 或使用 `run_demo.py` 内置的 `sys.stdout.reconfigure(encoding='utf-8')`（已包含）。

**Q: `DEEPSEEK_API_KEY` 设了但报告里还是 `llm_backend: local-fallback`？**
A: 检查 API Key 是否有效: `curl -H "Authorization: Bearer $DEEPSEEK_API_KEY" https://api.deepseek.com/v1/models`。如果返回 401,检查 key 格式（应该以 `sk-` 开头）。

**Q: Redis 没装怎么跑异步任务？**
A: 没 Redis 时,异步任务用 FastAPI BackgroundTasks 在 API 进程内执行。功能正常,但 API 重启会丢失正在排队的任务。对于开发和轻度使用足够了。

**Q: 如何清空历史任务记录？**
A: 删除 SQLite 数据库文件: `rm data/real_finan.db`。下次启动时自动重建空表。

**Q: 支持分析哪些公司？**
A: 内置样本数据: Apple、Microsoft。预置股票代码映射（支持行情数据）: Apple/Microsoft/Tesla/Amazon/Alphabet/Meta/NVIDIA/BYD/比亚迪/Toyota/Samsung/TSMC/Tencent/腾讯。其他公司需上传 PDF 或依赖 LLM 公开知识。

**Q: 报告生成需要多长时间？**
A: 有 DeepSeek API 时约 15-25 秒（4-6 次 API 调用），无 API 时约 2-3 秒（规则引擎直出）。

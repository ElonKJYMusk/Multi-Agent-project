   ## 关键文件详解

   ### `graph.py` (132 行) ⭐⭐⭐

   - **职责**：StateGraph 构建、条件路由定义、系统入口
   - **类**：`FinanceMultiAgentSystem`
   - **关键方法**：
     - `__init__` (39-57): 依赖装配
     - `_build_graph` (71-106): StateGraph 编译
     - `run` (108-131): 执行入口
   - **路由函数** (21-35): 4 个纯 Python 条件函数

   ### `agents.py` (753 行) ⭐⭐⭐

   - **职责**：7 个 Agent 的完整实现
   - **类**：`AgentRuntime`
   - **Agent 方法**（按执行顺序）：
     - `supervisor` (51-116): 公司识别 + 任务拆解
     - `retrieval` (121-189): 多源数据融合
     - `quantitative_analyst` (194-288): 指标计算
     - `psychologist` (293-310): 情绪分析
     - `critic` (315-387): 风险评分
     - `replanner` (392-404): 重规划/降级
     - `synthesizer` (409-752): 报告组装
   - **基础设施**：
     - `_record` (41-46): 审计日志

   ### `tools.py` (431 行) ⭐⭐⭐

   - **职责**：所有可复用工具函数
   - **关键函数**：
     - `SafeExpressionEvaluator` (13-69): AST 安全求值器
     - `safe_execute_formula` (72-75): 外部调用接口
     - `extract_companies_from_query` (158-212): 四级公司识别
     - `retrieve_company_payload` (88-155): 数据融合
     - `analyze_sentiment` (242-261): 规则引擎情绪分析
     - `analyze_sentiment_deep` (273-306): LLM 深度情绪分析
     - `calculate_derived_ratios` (309-328): 衍生指标计算
     - `build_chart_data` (331-399): 图表数据构造
     - `generate_scenario_analysis` (402-422): 情景推演
     - `parse_with_fallback` (425-430): JSON 容错解析

   ### `api/app.py` (184 行) ⭐⭐⭐

   - **职责**：FastAPI 应用工厂 + 路由定义
   - **关键函数**：`create_app(config)` — 工厂模式创建应用
   - **端点**：
     - `GET /`: 重定向到静态页面
     - `GET /health`: 健康检查
     - `GET /api/v1/config`: 配置信息
     - `POST /api/v1/analyze`: 同步分析
     - `POST /api/v1/analyze-upload`: 上传 PDF + 分析
     - `POST /api/v1/jobs`: 异步提交
     - `POST /api/v1/jobs/upload`: 上传 PDF + 异步提交
     - `GET /api/v1/jobs/{job_id}`: 任务状态
     - `GET /api/v1/jobs`: 任务列表

   ## 扩展指南

   ### 如何添加新的 Retriever 数据源

   1. 在 `market_data.py` 中实现新的 `_fetch_from_xxx()` 方法
   2. 在 `retrieve_company_payload()` 中添加数据源调用
   3. 在 `AppConfig` 中添加对应的配置字段和 API Key

   ### 如何添加新的 Agent

   1. 在 `FinanceState` 中添加新 Agent 的产出字段
   2. 在 `AgentRuntime` 中实现 `new_agent(self, state) -> FinanceState` 方法
   3. 在 `_build_graph()` 中注册节点 + 添加边
   4. 在 `_record()` 调用中添加审计信息

   ### 如何支持新的 LLM 模型

   1. 实现 `BaseLLMClient` 子类
   2. 在 `build_llm_client()` 中添加检测逻辑
   3. 在 `LLMSettings` 中添加对应的配置字段

   ### 如何添加新的数据库后端

   1. 在 `AppConfig` 中添加 `database_url` 的配置逻辑
   2. `SQLAlchemy` 通过 `create_engine(database_url)` 自动适配不同数据库
   3. 确保 `AnalysisJob` 模型的列类型在所有目标数据库中兼容
